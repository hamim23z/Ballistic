# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please do not open a public GitHub issue for security problems.

Report vulnerabilities privately using GitHub's "Report a vulnerability" button under the **Security** tab of this repository. Include:

- A description of the issue and its potential impact
- Steps to reproduce, or a proof of concept
- The affected file or route, if known

You can expect an initial response within 7 days. If the report is accepted, I'll work on a fix, keep you updated on progress, and credit you in the release notes if you want. If the report is declined, I'll explain why.

This is a personal portfolio project, so response times are best-effort.
